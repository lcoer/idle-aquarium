# Source and attribution

This application adapts the pure-web version of [wenonly/desktop-aquarium](https://github.com/wenonly/desktop-aquarium), commit `805450e148fbd8ff569e57fc5992afaa451872e4`.

Original source: `desktop-aquarium/index.html`. Copyright (c) 2026 wenonly. The complete upstream MIT license is preserved in `LICENSE`.

Adapted code includes fish steering, growth, feeding, mate selection, breeding, fish rendering, heart rendering and particle helpers. This version replaces the page layout and environment rendering, adds validated local persistence and accessible controls, and changes ecology timing for a calm non-predatory mode.

All visuals are generated by Canvas or inline SVG. No third-party image, font, sound, fish sprite or 3D asset is bundled. Skills in `.agents/skills` retain their own upstream license files and are development resources, not runtime dependencies.
